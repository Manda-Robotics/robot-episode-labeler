# Example episodes

Two single episodes cut from `lerobot/droid_1.0.1` (Apache-2.0), which is the
LeRobot conversion of **DROID: A Large-Scale In-the-Wild Robot Manipulation
Dataset** (CC-BY-4.0). Episode boundaries and task strings are taken from that
dataset's own episode metadata, not guessed.

| file | source episode | task string (verbatim from the dataset) |
|---|---|---|
| `droid_blue_block_in_green_bowl.mp4` | file-000, episode 1, 11.133–28.867 s | Put the blue block in the green bowl |
| `droid_duvet_tip_left.mp4` | file-000, episode 2, 28.867–56.267 s | Move the bottom right tip of the duvet to the left |

Used as public demo material because both licences permit commercial use with
attribution.

**Not** used for this: WGO-Bench (`macrodata/WGO-Bench`) is CC-BY-NC-SA-4.0. It is
our development benchmark only, and must never appear as demo content on a public
model page or in any commercial artifact.
